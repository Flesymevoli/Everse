# 轻量 UX 约定

正文是主体，应用采用暖纸色、深灰正文和低饱和暖色强调。正文约 780px 宽，使用中文衬线字体回退与宽松行高。玩家输入呈弱化行动记录，数据库仍保留每轮边界。

桌面采用三栏：左侧作品展开各自存档、中央连续阅读与输入、右侧角色信息（人物简介、状态与背包区域）。两侧可收起，API 设置仍按需打开。初始宽度达到 1120px 时展开右栏；更窄时角色信息通过“角色”按钮打开覆盖面板，760px 以下默认隐藏书架。右栏简介来自角色卡，状态与背包尚未接入数据，明确显示空状态；世界书、初始场景与兼容性提示归入设置。展开或收起作品不切换游戏，点击具体存档才加载，作品内提供新建存档入口。输入始终自由，建议只填入可编辑输入框。开关默认关闭，按存档保存。生成时显示停止入口；中断保留未保存草稿与输入。

行动建议开关位于输入框上方，以小胶囊显示开关状态；未进入存档时禁用。输入框右下方可切换模拟模型与已配置模型，更多模型通过设置填写。发送使用圆形上箭头，保留可访问名称。

复制操作悬停、键盘聚焦或触屏可见。消息编辑与撤销位于按需管理区；最新回复提供重新生成，存在多个候选时显示左右切换和编号，生成中禁用候选操作。作品编辑器另行实现。此文档作为后续 UI 调整约定，随实现迭代。

API 设置允许多个命名连接，各自包含地址、模型和 Key；主界面模型菜单显示连接名称与模型 ID。添加不自动启用，用户显式选择后下一轮生效。生成时禁用编辑与切换；删除当前连接回到模拟模式。名称/地址/模型和明确选择的连接在本浏览器保留；刷新不自动发送请求。临时 Key 刷新清空，已保存 Key 由后端加密保存。

## 当前入口更新（YunoTavern）

作品库分世界书/角色卡，各有新建和导入；展开卡片查看关联存档。新建存档进入开局准备，选择已有作品或填写简单设定。角色卡提供编辑入口，表单仅含名称、人物设定、性格、场景和开场，明确告知下一轮生效、不改已有聊天。世界设定允许极简文本。

API 连接增加“保存连接与 Key”“删除已保存 Key”。保存后不显示 Key 内容，以 hasKey 状态提示；留空保留，填入新值替换。已保存连接有未保存修改时禁止发送，要求先保存，避免界面和实际请求不一致。刷新保留已选连接，不需重填已保存 Key。此节取代此前“Key 刷新后必须重填”的阶段约定。

## 世界书命名与编辑

所有面向用户的名称统一为“世界书”。展开世界书点击“编辑世界书”；可编辑名称、设定、开场和基础条目。关键词按行输入，支持常驻、停用、新增和确认移除。取消不写入，保存才生效。管理区的独立世界书使用同一个条目编辑组件。明确提示所有引用此书的存档下一轮生效，不改旧聊天和开场；高级字段未展示但保留。

## 响应式表单与创建引导（2026-11-09）

设置、世界书/角色卡编辑、独立管理区统一表单样式：标签在上，文本控件满宽且 min-width 为 0；正文文本域最小高 128px，关键词 80px，控件/按钮触摸目标至少 44px。复选框单独使用横排标签；预算等网格在 520px 以下改为单列，按钮自动换行。桌面面板最多 600px，窄屏用满可用宽度，不用隐藏横向溢出掩盖问题。

新建作品表单按“背景—可选玩家身份—开场”给提示，名称可空；“更多设定”保留条目与角色高级字段。主按钮“创建并准备开局”，次按钮“仅保存作品”，没有新模式。占位示例不会写入数据，不自动扩写。玩家身份独立于故事人物，可后续编辑。

## 开局准备增量

新建存档现在进入正文区域内的准备页：故事与人物、可选玩家身份、开场选择/编辑/预览。保存准备可稍后续填；确认有开场后才进入阅读和自由输入。新建作品主按钮改为“创建并准备开局”；不再通过旧的组合选择弹窗直接进入空白聊天。玩家身份在准备页按存档保存，覆盖作品默认值，不修改原作品。具体行为见 OPENING-FLOW.md。


设置默认勾选“自动管理上下文与回复预算”，取消后显示高级数值；不再使用未经验证的统一 max 属性。文字明确提示供应商默认输出可能影响费用、预设预算优先。错误区分本地配置冲突与 API 拒绝；不自动重试。
# 本轮开局与状态交互更新

导入入口已增加 Word `.docx`。导入成功后先检查设定框中的文字，可继续编辑；兼容提示与“下载原始 Word 文档”链接保留。错误不清空已有设定，不自动生成或调用 AI；旧 `.doc` 提示另存为 `.docx`。详细支持范围见 WORD-IMPORT.md。

侧栏“创建故事 / 导入设定”进入原有准备页，不增加独立快速模式。首先写几个字或导入 UTF-8 TXT/Markdown；已有角色/世界资料与玩家身份按需展开。有作者开场时可直接选择和预览，无开场才主动生成；从不自动付费调用。

确认后独立文本故事列在“我的故事”，卡片作品仍在原分类下。顶部“状态”打开可收起侧栏，展示真实记录、引用和玩家修正。修正保存后从下一轮生效，可撤销；不要求每轮审核。生成中禁改。旧存档可自行开启状态记录，不自动分析全部历史。

流式正文隐藏状态协议，解析失败不把正文草稿冒充成功存档。重新打开存档可查看/复制未提交草稿、恢复原行动；重试需用户主动触发。Prompt Inspector 显示选中记忆、遗漏数量和按需读取的实际用量记录。
