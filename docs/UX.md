# 轻量 UX 约定

正文是主体，应用采用暖纸色、深灰正文和低饱和暖色强调。正文约 780px 宽，使用中文衬线字体回退与宽松行高。玩家输入呈弱化行动记录，数据库仍保留每轮边界。

桌面采用三栏：左侧作品展开各自存档、中央连续阅读与输入、右侧故事状态。两侧可收起，API 设置仍按需打开。初始宽度达到 1120px 时展开右栏；更窄时通过“状态”按钮打开覆盖面板，760px 以下默认隐藏书架。右栏展示角色简介、玩家身份、有依据的状态与玩家引导；“调整人物与故事引导”按需展开人物、状态/背包、世界观、剧情走向编辑。保存后从下一轮生效，不改原作品与旧剧情。生成中禁改；清空字段并保存即可撤销相应引导。

点击作品只展开存档，点击具体存档才加载；存档旁三点菜单提供重命名与存档设置，设置在独立窗口中打开，复用已有世界书、预设、模型参数及聊天管理能力。新建流程的开局准备页可填写可选存档名称，保存准备和确认开始都会保留。阅读区独立滚动，输入框保持在下方；接近正文末尾时跟随生成，向上阅读时不强拉到底。建议编号可点击，但只填入输入框。新确认开局默认开启建议，旧存档和明确关闭的偏好保留；作者约定的格式优先，无约定采用应用协议。清晰标题后的简单列表作为兼容入口，复杂格式保留原文，不猜测。生成时显示停止入口；中断保留未保存草稿与输入。

行动建议开关位于输入框上方，以小胶囊显示开关状态；未进入存档时禁用。输入框右下方可切换模拟模型与已配置模型，更多模型通过设置填写。发送使用圆形上箭头，保留可访问名称。

复制操作悬停、键盘聚焦或触屏可见。消息编辑与撤销位于按需管理区；最新回复提供重新生成，存在多个候选时显示左右切换和编号，生成中禁用候选操作。作品编辑器另行实现。此文档作为后续 UI 调整约定，随实现迭代。

API 设置允许多个命名连接，各自包含地址、模型和 Key；主界面模型菜单显示连接名称与模型 ID。添加不自动启用，用户显式选择后下一轮生效。生成时禁用编辑与切换；删除当前连接回到模拟模式。名称/地址/模型和明确选择的连接在本浏览器保留；刷新不自动发送请求。临时 Key 刷新清空，已保存 Key 由后端加密保存。

## 当前入口更新（Everse）

作品库分世界书/角色卡，各有新建和导入；展开卡片查看关联存档。新建存档进入开局准备，选择已有作品或填写简单设定。角色卡提供编辑入口，表单仅含名称、人物设定、性格、场景和开场，明确告知下一轮生效、不改已有聊天。世界设定允许极简文本。

API 连接增加“保存连接与 Key”“删除已保存 Key”。保存后不显示 Key 内容，以 hasKey 状态提示；留空保留，填入新值替换。已保存连接有未保存修改时禁止发送，要求先保存，避免界面和实际请求不一致。刷新保留已选连接，不需重填已保存 Key。此节取代此前“Key 刷新后必须重填”的阶段约定。

## 世界书命名与编辑

所有面向用户的名称统一为“世界书”。展开世界书点击“编辑世界书”；可编辑名称、设定、开场和基础条目。关键词按行输入，支持常驻、停用、新增和确认移除。取消不写入，保存才生效。管理区的独立世界书使用同一个条目编辑组件。明确提示所有引用此书的存档下一轮生效，不改旧聊天和开场；高级字段未展示但保留。

## 响应式表单与创建引导（2026-11-09）

设置、世界书/角色卡编辑、独立管理区统一表单样式：标签在上，文本控件满宽且 min-width 为 0；正文文本域最小高 128px，关键词 80px，控件/按钮触摸目标至少 44px。复选框单独使用横排标签；预算等网格在 520px 以下改为单列，按钮自动换行。桌面面板最多 600px，窄屏用满可用宽度，不用隐藏横向溢出掩盖问题。

新建作品表单按“背景—可选玩家身份—开场”给提示，名称可空；“更多设定”保留条目与角色高级字段。主按钮“创建并准备开局”，次按钮“仅保存作品”，没有新模式。占位示例不会写入数据，不自动扩写。玩家身份独立于故事人物，可后续编辑。

## 开局准备增量

新建存档现在进入正文区域内的准备页：故事与人物、可选玩家身份、开场选择/编辑/预览。保存准备可稍后续填；确认有开场后才进入阅读和自由输入。新建作品主按钮改为“创建并准备开局”；不再通过旧的组合选择弹窗直接进入空白聊天。玩家身份在准备页按存档保存，覆盖作品默认值，不修改原作品。具体行为见 OPENING-FLOW.md。


设置默认勾选“自动管理上下文与回复预算”，取消后显示高级数值；不再使用未经验证的统一 max 属性。文字明确提示供应商默认输出可能影响费用、预设预算优先。错误区分本地配置冲突与 API 拒绝；不自动重试。
# 本轮开局与状态交互更新

失败开场可通过独立的“恢复上次开场（不调用 AI）”按钮取回，仍需预览确认；生成失败后刷新当前存档的草稿状态，使恢复入口立即可见。长文分类放在准备页折叠区，不恢复右侧常驻编辑器。按页查看原文、手动改分类，模型分析必须主动点击并注明收费与批次范围。

导入入口已增加 Word `.docx`。导入成功后先检查设定框中的文字，可继续编辑；兼容提示与“下载原始 Word 文档”链接保留。错误不清空已有设定，不自动生成或调用 AI；旧 `.doc` 提示另存为 `.docx`。详细支持范围见 WORD-IMPORT.md。

侧栏“创建故事 / 导入设定”进入原有准备页，不增加独立快速模式。首先写几个字或导入 UTF-8 TXT/Markdown；已有角色/世界资料与玩家身份按需展开。有作者开场时可直接选择和预览，无开场才主动生成；从不自动付费调用。

确认后独立文本故事列在“我的故事”，卡片作品仍在原分类下。顶部“状态”打开可收起侧栏，展示真实记录、引用和玩家修正。修正保存后从下一轮生效，可撤销；不要求每轮审核。生成中禁改。旧存档可自行开启状态记录，不自动分析全部历史。

流式正文隐藏状态协议，解析失败不把正文草稿冒充成功存档。重新打开存档可查看/复制未提交草稿、恢复原行动；重试需用户主动触发。Prompt Inspector 显示选中记忆、遗漏数量和按需读取的实际用量记录。

Alpha 更新：输入旁“记为世界设定”明确保存输入原文到当前存档世界观，不发送行动、不调用模型，右侧可修改或删除。完整正文的辅助状态失败以轻量警告提示，不阻断下一轮；旧开局问答过期时提示未采用并继续当前设定。取消、断流和空回复仍按草稿处理。

## 局部正文编辑

选中同一条 AI 回复内的文字，点击“修改选中文本”；也可使用回复旁的“编辑”处理整条正文。支持手动输入或清空选区，也可填写要求、点击 AI 生成预览。生成使用当前连接，一次调用，不自动重试；有停止入口。确认前不改变存档，取消丢弃本次编辑。手动修改后需重新预览。

“恢复最近编辑前的版本”先显示预览，再确认。只恢复最近编辑且正文没有新进度的版本，避免覆盖新剧情。改动事实时可以填写明确修订；已有后续剧情、手工世界引导需要玩家检查，不承诺自动消除所有矛盾。窄屏使用可滚动对话框，底层阅读区域不可误操作。

### 行内改写交互更新

选择正文中的大致范围，松开鼠标或完成键盘选择后，在最后选中段落下方直接出现小编辑框；范围自动扩展到同一回复内触及的完整段落，并以淡底色标示。无需精确拖到每个字，不跳转、不遮罩整页。输入要求后点击箭头生成；也可切换手动修改。

预览直接替换正文显示：陶土色底色与下划线标识新增，淡陶土底色与删除线标识移除；接受后才写入存档，取消还原。接受后本次修改保留新增范围高亮，刷新后高亮清除，正文与旧版本仍持久保存。事实修订与上下文默认折叠；恢复也使用同一行内预览。跨回复选区暂不处理，可逐条编辑。此节替代前版弹窗交互规范。

### 临时侧栏编辑（Figma 对照后的首步）

选区默认只出现“改写描述 / 手动修改 / 取消”工具条。点击后打开临时右栏，取代角色信息；关闭恢复先前角色栏状态。原文、改写要求、修改后预览和应用入口集中展示，正文保留陶土色差异。窄屏使用底部可滚动面板。此节替代直接展开完整行内编辑框的交互。

当前只接通正文修改，事实修订复用已有能力。附件设计中的剧情影响范围、写入世界设定与另存为分支尚未接入此面板，不展示无作用的按钮。Figma 文件 5WwsXZ77fdCx0hiD1nBWy6 的 2:2 为桌面阅读参考；本轮未整体替换阅读页或硬编码原型人物数据。

### 批注式 AI 编辑与动态角色面板（当前）

选区工具条展开正文旁的小批注框，右栏始终保留角色信息；不再打开独立编辑侧栏。移除润色/扩写/精简快捷按钮与单独事实输入框，保留自由要求、手动编辑、预览、确认和取消，陶土色展示差异。“同步更新设定”默认关闭，每次修改明确选择；开启后确认才将选区修订保存为当前存档的后续参考，不修改原角色卡、世界书，不另调用模型。

右栏优先分人物展示作品自定义字段及随身物品；其余世界背景、历史和剧情引导折叠查看。没有来源的属性不显示，不硬编码生命值或等级。每个字段可查看依据并手动修正；修正当前状态后，后续有正文依据的新变化可继续更新该字段。旧存档不会自动付费补算，开启故事记忆后从下一轮更新。修改正文后旧派生状态失效，下一轮生成再建立新的有依据状态；不声称立刻理解所有语义变化。
