# 预设 / Mod：第一阶段

入口：设置 → 预设 / Mod → 添加设定。新建、编辑、复制、确认删除、JSON 导入和全部导出已实现。新建默认关闭；复制和导入也默认关闭，不覆盖同名模块。导入目前只接受 `everse_prompt_modules_v1`，不支持的字段会拒绝，而非丢弃。

本阶段是**全局、常驻**模块。开关真正控制是否进入下一次请求；类型「预设 / Mod」只用于管理，不增加模型调用或自动执行代码。前置词在完整上下文之前，后置词在完整上下文之后，两组内均按优先级升序、顺序升序、ID 排列。优先级是排列规则，不保证模型服从冲突指令。

常规生成、重新生成、开场兼容接口、局部改写复用 `buildContext`，均注入启用模块并计入既有预算。文档分类等辅助分析不注入叙事模块。生成进行中使用开始时的快照，编辑从下一次请求生效。Prompt Inspector 的 `activeModules` 和 `messages` 显示实际展开宏后的内容。禁用模块不会发送；原始剧情、动态记忆及世界书不被改写。

酒馆 Chat Completions 预设仍通过原导入入口保存完整原始 JSON、兼容警告及现有 `prompt_order` 行为。其原有编排位于 Everse 前后置词之间；没有把它强行转换成新模块，也未增加此前不支持的高级酒馆语义。

后续依赖顺序：作用范围及覆盖规则 → 关键词和单轮手动触发 → 自定义深度位置 → 扩展酒馆兼容。这些尚未实现，界面没有可点击的占位选项。当前模块也不会建立新的状态解析器或执行插件脚本。

关键文件：`shared/prompt-modules.ts`（格式、排序），`server/prompt-modules.ts`（持久化接口），`server/context.ts`（注入、预算），`src/PromptModules.tsx`（列表及编辑），`tests/prompt-modules.test.ts`（持久化和实际请求）。数据复用 SQLite assets 表的独立 kind，不混入记忆。
