# 对话式开局（2026-11-09）

填写或导入设定 → 进入故事 → 展示作者已有开场，或主动「按设定开始」/自由输入 → 用普通文字回答初始化问题 → 持续互动。

- 无开场也可以进入并保存，刷新后不会返回准备页。不要求开场预览或固定角色问卷。
- 进入、刷新不调用模型。点击「按设定开始」走普通流式回合，每次只请求一次，可停止；选择、人物回答和剧情完整保存。
- 作者自带开场和备选开场保留；旧草稿、身份和已回答的旧版问答兼容。旧开场生成/问卷 API 保留兼容，但新界面不使用。
- 首轮长文检索使用开局阶段，优先载入初始化相关片段。后续沿用现有检索与上下文；不宣称已理解整份长文，模型仍可能误解规则。
- 新确认存档标记 `conversationalStart`，提示模型尊重作者初始化顺序、不代填身份、不重复已回答问题；旧存档不自动加此提示。
- `server/preparation.ts` 事务绑定资源：有开场写一条 assistant 消息，无开场保持空消息。`openingState=started` 决定是否进入阅读界面，不再按“消息为空”强制返回准备。
- 已开始的存档仍禁止再次确认开局覆盖原文。原角色卡、世界书、预设语义与存档数据保持兼容。

验收：76 项测试通过；桌面与 375px 手机浏览器验证无开场进入、刷新恢复、主动首次生成、下一轮自由回复。使用隔离数据库与假 API，无实际模型费用。
