# 产品需求

YunoTavern：本地优先的开源文字游戏，面向希望直接导入作品、使用自有 API 游玩的读者。

Spend tokens on storytelling, not infrastructure.

MVP 包含 JSON V2/V3 卡导入、关键词世界书、流式聊天、SQLite 存档、API 配置和 Prompt Inspector。验收流程为导入卡、选择角色、新建游戏、发送一句话、看到流式回复、刷新后恢复原文。

本阶段暂缓桌面安装包、多人、自动世界模拟、摘要记忆、Tool Calling 和完整预设兼容。长期以作品原样复用为目标，逐步扩大格式兼容并公开差异。

# 开发优先级更新（2026-11-09）

优先实现 SillyTavern 原生核心功能与真实行为，按 docs/COMPATIBILITY.md 的依赖顺序推进。独立阅读 UI 保留；右侧仅角色信息，复杂管理按需打开。自定义状态/背包、世界模拟不优先于角色卡、世界书、预设、模型参数和聊天管理兼容。保留字段不等于执行字段，不以界面完成代替请求与数据验收。

## 当前增量验收

世界书和角色卡可分别新建/导入，存档选择至少一类资源组合开局。角色卡可编辑基础字段，不扩写、不丢未知字段、不重写旧聊天。多个 API 连接可在 Windows 加密保存 Key，刷新后继续使用，支持替换和删除；不向浏览器回传已保存密钥。世界书属于应用资源组合，不等同酒馆世界书格式本身。

世界书也支持基础编辑：名称、世界设定/开场、关键词条目。验收要求与角色卡一致：保存后下一轮使用新内容，已有存档消息与分支不改写，未知高级字段保留，生成期间不允许改动共享资源。
