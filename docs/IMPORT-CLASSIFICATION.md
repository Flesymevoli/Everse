## 分类入口与真实作用

当前入口在 **长文 DOCX 的准备页 → 检查与修正资料分类**。先读取原文与分类，可免费手动选择，或主动使用当前连接分析下一批。每批最多8个分析单元/6000字符，另附一个前置单元作为上下文，一次请求；不自动循环全文、不自动付费重试。供应商回复默认长度仍可能影响费用。分类调用记录包括失败及未知用量，不把未知记为零。

- 核心规则与叙事要求：作为持续上下文保留，不因检索未命中静默删除。
- 开局引导：只进入开场请求。
- 世界/人物资料、条件机制：按情境匹配选取。
- 示例文本：默认不进入叙事请求，不作为已发生事件。
- 未分类：保留原文并作为待检索资料，界面显示待复核数量。

正文不改写。人工修改不会被后续模型批次覆盖。结果与原文 hash、字符范围和版本绑定；刷新重用已完成结果，版本冲突拒绝覆盖。修改共享文档分类会影响引用该文档的存档的下一次请求，不重写已生成剧情。

核心规则/叙事要求过多时可能超过资料软目标，但不会悄悄丢弃；仍受总上下文预算检查。自动预算可能扩大必要内容，不能承诺总Token降低。Inspector列出实际采用的分类及位置、未分类数量、是否超过软目标。

## 实现与边界

`shared/document-plan.ts` 定义分类；`server/document-plan.ts` 负责段落分析单元、源版本、批次与严格结果校验；`server/document-context.ts` 实际编排；`src/DocumentPlanEditor.tsx` 提供原文查看、人工修改和按需模型调用。

目前先以原始段落建立分析单元，单段过长时做有界分割；模型为这些单元提出语义类别。**尚不是完整语义切分**，混合段落标未分类，尚无段内拆分/跨段合并界面、完整交叉引用或规则冲突推理。已经判为未分类的模型结果需人工复核，不自动再次付费分析。尚未把分类入口推广到短文/TXT/ST作品；原有导入功能保持。

事件因果记忆、阶段摘要和后台NPC调度尚未实现。本次没有真实付费模型质量评测，不能依据模拟分类证明语义准确性。
