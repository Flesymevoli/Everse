# Everse 界面风格规范

可迭代的实现约定。参考 [Figma Reader 2:2](https://www.figma.com/design/5WwsXZ77fdCx0hiD1nBWy6?node-id=2-2)，不是最终视觉定稿。

## 色彩与字体

- 阅读背景 `#fbfaf6`，书架 `#f3f0e9`，状态栏 `#f6f3ed`。
- 正文 `#2e2a26`；辅助信息 `#86796e`，不能用于重要提示的小字号正文。
- 配色沿用 Figma 的温暖底色与辅助色思路；Claude 仅参考留白、层级、克制的边框和轻量交互，不复制界面。
- 按原型实际用途分配颜色：作品首字封面采用棕 `#a47a68`、灰绿 `#a09f89`、灰褐 `#b4a495` 三色，按作品名称稳定分配，同一作品在最近继续和书架中一致。当前存档是米色底和陶土色 `#b97860` 细标记，不使用绿色选中底。
- 绿色只点缀真实状态：载入状态点 `#799884`；开启故事记忆用 `#657961` 字色与 `#e9e7dc` 底色。保留状态文字，不仅靠颜色。
- 生成与改写的交互强调为陶土色 `#a5634c`，选中底色 `#eae1d6`，细分隔线 `#e8e3da`。
- 改写新增、删除、选区统一使用陶土色系，同时使用增删标记；不以绿色表示修改。
- 全应用统一使用 `--font-app`：Noto Serif SC / 宋体（Songti SC、SimSun），西文回退 Georgia、serif，保留原有书卷感。小说正文、标题、侧栏、表单、改写预览均使用同一衬线字体族；层级仅通过字号、字重和行高区分。正文桌面 18px、窄屏 17px、行高 1.95，最大宽度 650px。

## 布局

- 左侧 246px：品牌 → 新建故事/导入 → 最近继续 → 我的世界（展开存档）→ 高级资源管理 → 设置。
- 不伪造封面、章节、进度或更新时间。没有封面时使用作品首字。
- 中央正文连续阅读，玩家行动弱化。输入区固定在阅读区域下方，正文独立滚动。
- 桌面右侧 298px，从顶端展示角色与状态；属性为两列浅底网格，物品为单列，依据和修正操作按需展开。字段由作品决定，不写死样例属性。
- 顶栏显示当前故事路径和实际载入/处理状态；已打开故事的标题左对齐。世界设定与剧情引导按需展开。
- 760px 以下书架收为抽屉；触屏操作至少 44px。宽度不足时折叠辅助内容，不挤压小说。
- 间距优先使用 4 / 8 / 12 / 16 / 24 / 32px；不用多层卡片包裹正文。

## 交互与状态

- 存档菜单提供删除入口：显示名称、说明永久删除范围，确认后执行；取消或失败时保留，生成期间禁止删除，共享资料不删除。
- 世界 → 存档使用展开树；存档的更多操作沿用三个点。高级角色卡、世界书导入编辑能力保留。
- 选文后就地提出改写要求，先预览再确认；支持取消和恢复。同步更新设定默认关闭。
- 「记为世界设定」位于右侧「设定与剧情引导」内，有独立输入框；不消耗模型调用、不发送玩家行动。
- 无模型时显示配置入口，不提供模拟模型，不静默回退。生成中保留停止入口；错误不清空玩家草稿。
- 键盘焦点必须可见；选中状态同时用背景和位置标记。加载不改变输入区位置。
- 不允许阅读区横向滚动；纵向滚动条使用细暖灰色，保留鼠标、触摸和键盘滚动能力。

## 实现与边界

主题变量及布局覆盖在 `src/figma-layout.css`；基础与功能样式在 `src/style.css`。本地 SVG 位于 `public/figma/`，来自上述 Figma 原型。

应用导航、编辑操作保持一致；作品可决定叙事风格及角色字段，不能覆盖应用的安全提示、操作语义或可访问性。每次新增交互同步更新此规范，不将原型中未实现的功能写成现有能力。

## 与原型有意保留的差异

按用户确认保留统一衬线字体、首字母大写的纯文字 Everse 标识、圆形发送按钮和就地改写。原型中没有业务实现的附件、章节时间、进度及示例人物状态不伪造。窄屏使用抽屉；状态证据和修正按钮可展开，保持可操作。
