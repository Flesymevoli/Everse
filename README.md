# Narrative Slice

Spend tokens on storytelling, not infrastructure.

本地优先、独立实现的 AI 文字游戏 Vertical Slice。项目暂名 Narrative Slice，使用 MIT 许可证。当前是开发版，需要 Node 24.20+，尚无桌面安装包。

## Windows 启动

在本文件所在目录打开 PowerShell。

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。后端仅监听 127.0.0.1:8787。退出开发服务用 Ctrl+C。已安装依赖的本机可直接执行第二条命令。

1. 导入 `examples/lantern.json` 或自己的 V2/V3 JSON 卡。
2. 展开作品，点击“新建存档”，默认免费模拟模式。有备选开场的角色可在首次互动前选择开场白。
3. 输入“我走向灯塔。”，发送并查看回复、Prompt Inspector 中的关键词条目。
4. 刷新网页，点击左侧存档恢复原文。
5. 使用自有 API 时展开设置，点击“添加 API 连接”，填写连接名称、Base URL（例如 https://api.example.com/v1）、模型 ID 与 API Key；在输入框旁的模型菜单选择该连接。密钥仅保留在当前页面内存，刷新后重填。开发者未调用付费 API。

## 已实现

角色基础信息和开场白导入、作品选择、多个本地存档、流式回复、完整回合自动保存、内嵌世界书基础关键词匹配、请求上下文和估算预算检查。原文存储于 `data/game.sqlite`，重启保留。预算只裁剪发送历史。失败回合不保存，输入保留供重试。连接意外中断时先重新打开存档确认是否已提交。

卡片的 system_prompt 和 post_history_instructions 会参与请求。纯文本渲染不执行导入内容。兼容警告列出保留但未使用的字段。

## 当前限制

- 支持 JSON V2/V3 和 PNG tEXt 中的 chara/ccv3 数据导入（ccv3 优先，上限 2 MB；尚不保存头像或导出 PNG）。独立世界书与 Chat Completions 预设支持部分语义，详见兼容性清单。CHARX、示例对话、脚本、正则、MVU 尚未实现。备选开场仅支持单人存档首次互动前选择；重新生成和 Swipe 已支持基础候选保存与切换。
- 普通文本仅替换 {{char}} 和 {{user}}，玩家称呼固定为“玩家”；角色覆盖预设时另外支持 {{original}}。内嵌世界书仍扫描最近 6 条消息和本轮输入；独立世界书支持可配置扫描、递归、概率与深度插入，两者尚未统一。
- Token 用 UTF-8 字节与消息开销估算，偏保守，不能替代供应商精确计数。
- API 使用 Chat Completions 文本 SSE，无工具调用。供应商私有格式和所有真实模型尚未验证。
- 单机单服务进程；无多用户认证、永久删除存档、自动记忆、桌面发行包；可归档与导出 JSONL。备份数据库前停止服务。
- 应用使用基础中性样式，作品视觉主题尚未实现。

## 阅读体验更新

暖纸色连续阅读界面、弱化的行动记录、可折叠书架与按需设置。行动建议默认关闭，按存档保存，启用后通过同次生成的末尾 JSON 区块获取 2～3 项，点击只填入输入框。格式失败保留原始正文，不自动重试。可停止上游生成，中断回合不保存，草稿保留在页面。复制、管理区消息编辑/撤销和阅读区重新生成/候选切换已实现；角色卡/世界书直接编辑删除仍待实现。

## 世界书、预设与聊天管理

进入存档后打开设置中的“管理世界书、预设与聊天”。可导入 examples/worldbook.json 和 examples/chat-preset.json，选择绑定到当前存档，再发送“我走向灯塔”检查 Prompt Inspector 的命中条目、消息顺序和参数。新功能为部分兼容，准确边界见兼容性清单文末。采样覆盖按存档保存，不保存 API Key。支持 JSONL 导入导出、改名、归档恢复、消息编辑撤销和分支；归档不删除数据。

## 本轮验收与试玩

2026-11-09：生产构建（包含严格类型检查）和 19 项自动测试通过。测试只使用模拟回复与本地 HTTP 服务，未验证真实供应商。浏览器管理流程的实际点击验收仍未完成：上一轮 Windows 自动化无法可靠识别页面地址而停止，不能以接口测试代替界面验收。

API 设置即时作用于下一次发送，无需另存密钥。Base URL 填服务商的 Chat Completions 根地址（通常以 /v1 结尾），不要包含 /chat/completions；程序会追加该路径。模型 ID 必须与服务商一致。添加连接后点击“使用此连接”，或在主界面输入框旁选择连接，即可开始。Key 经本地后端转发为 Authorization: Bearer，不写入 SQLite、localStorage 或应用日志；连接名称、地址和模型保存在本浏览器；刷新后 Key 清空，并恢复免费模拟模式。默认模拟回复是固定示例，不代表真实模型的剧情质量。

每个完整回合自动保存。最近一次回复可重新生成；成功后追加候选，失败或停止时原回复保持不变。箭头切换候选后，下一轮使用选中的正文；重生成不会清空尚未发送的输入。

## 多 API 连接

设置 → 添加 API 连接，可分别配置多个服务或同一服务的不同模型。主界面输入框右下角的菜单按连接名称列出模型，切换影响下一次发送及重新生成；生成过程中禁止切换或编辑连接。删除连接需确认，删除当前连接会回到模拟模式，不影响故事存档。连接信息仅在当前浏览器保存，不跨设备同步；所有 Key 仅在页面内存。地址不接受内嵌账号密码、查询参数或片段。

本次构建与 22 项测试通过，新增双本地 HTTP 服务集成测试验证目标地址、模型和认证头随连接切换，未使用真实 API。浏览器点击验收仍待完成。
